# Spring Product Service
## Módulo 2 — Spring Boot Core

Este projeto é a **implementação de referência** do exercício final do **Módulo 2** do grupo de estudos Java.  
Ele evolui a aplicação Java “plain” do Módulo 1 para um **microserviço REST com Spring Boot**, mantendo foco em fundamentos e clareza arquitetural.

---

## 🎯 Objetivo

Demonstrar na prática:

- Uso consciente do **Spring Boot 3.x**
- Uso de **Java 21**
- Criação de **API REST**
- Uso de **records** como DTOs
- Separação mínima de responsabilidades (Controller / Service)
- Serialização automática JSON (Jackson)
- Build com **Maven**
- Execução local e via **Docker**

> ❗ Não há banco de dados, segurança ou mensageria.  
> O foco é entender **o core do Spring Boot**.
